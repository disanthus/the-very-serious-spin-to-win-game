# The Very Serious Spin to Win Game

A 3D game developed solo in Godot and GDScript during a
seven-day game jam.

## Features

- 3D environments
- Player movement
- Interactive objects
- Interactive computer
- Custom 3D models
- Original narrative
- Multiple gameplay elements
- Adjustable volume controls

## Development

Developed and published within seven days.

## My Contributions

- Game programming
- Scene design
- Character movement
- Object interaction
- 3D modeling
- Narrative development
- UI/accessibility improvements
